**В этом репозитории находятся и фоновый трекер, и расширение Google Chrome.** Сайт [Time & Games](https://github.com/GameModify/time-and-games) выпускается отдельно: он показывает историю, графики и библиотеки, а трекер собирает активность.

## Как устроена система

| Компонент | Что делает | Нужен ли отдельно |
| --- | --- | --- |
| **Activity Tracker** | Определяет приложения Windows, игры, документы и сохраняет интервалы в SQLite | Отдельное приложение в трее |
| **Расширение Chrome** · входит в поставку | Передаёт активные сайты, действия во вкладках и состояние видео | Нужно для браузерной активности; подключается к трекеру |
| **[Time & Games](https://github.com/GameModify/time-and-games)** | Таймеры, классификация, статистика и библиотеки игр/кино | Самостоятельный сайт, подключается по локальному API |

> **Сайт работает и без трекера.** Трекер тоже может собирать данные без открытого сайта и предоставляет собственные настройки и API. Для удобного просмотра и анализа истории подключи Time & Games. Остановка одного компонента не завершает остальные.

## Быстрый старт

1. Скачай **`ActivityTracker-<версия>-windows-x64-setup.exe`** из [релизов](https://github.com/GameModify/activity-tracker/releases/latest).
2. Установи и запусти приложение. В трее появится **фиолетовый значок часов**. Node.js отдельно не нужен.
3. В меню значка открой настройки и скопируй **ключ для сайта**.
4. Запусти [Time & Games](https://github.com/GameModify/time-and-games/releases/latest). В **Настройки → Автоматический учёт** укажи `http://127.0.0.1:3536` и ключ.
5. Для сайтов и видео добавь расширение Chrome по инструкции ниже.

Установка выполняется для текущего пользователя без прав администратора. Автозапуск предлагается отдельно и по умолчанию выключен. Рядом с файлами релиза опубликован `SHA256SUMS.txt`.

## Расширение Chrome

**Расширение уже включено в установщик и переносимый архив.** В релизах есть и отдельный файл `ActivityTracker-Chrome.zip`. Публикации в Chrome Web Store пока нет.

1. В меню трекера выбери **«Браузерное расширение»**.
2. Открой `chrome://extensions`, включи **режим разработчика** и нажми **«Загрузить распакованное расширение»**.
3. Выбери открытую папку `chrome`. Отдельный ZIP сначала распакуй.
4. В настройках расширения укажи локальный адрес сервиса и **ключ отправки** из настроек трекера.
5. Включи сбор для выбранных сайтов или разреши все HTTP/HTTPS-сайты. Исключения можно настроить отдельно.

По нажатию на значок расширения видно, какая вкладка и видео считываются и доходят ли события до сервиса. Разрешения, исключения, научный чат и диагностика доступны в настройках.

## Что учитывается

| Источник | Как определяется активность |
| --- | --- |
| Приложения Windows | Активное окно, ввод и настраиваемое время бездействия |
| Игры | Steam и сохранённые правила; закрытие игры и краткий Alt-Tab различаются |
| Word | Окно документа и подтверждённый путь; можно назначить рабочую папку |
| Сайты и чаты | Фокус вкладки и признаки взаимодействия |
| Видео | Воспроизведение и пауза плеера, в том числе во встроенных кадрах |
| ChatGPT и Codex | Проект, обычный чат и доступные признаки голосового ввода |
| Discord | Подтверждённое голосовое соединение при доступном интерфейсе клиента |

<details>
<summary><strong>Правила, проекты и точные интервалы</strong></summary>

Категории можно назначать приложениям, сайтам, документам, каналам и отдельным видео. Time & Games управляет классификацией через API, а расширение позволяет выбрать категорию YouTube рядом с каналом.

Паузы и смена фокуса сохраняются как границы интервалов. Повторная доставка событий не создаёт вторую запись, потеря связи не превращается в рабочее время. Возможности конкретного источника зависят от разрешений и доступных сигналов.

[Подробности источников и правил](docs/guide.md).

</details>

<details>
<summary><strong>Управление из трея и переносимый вариант</strong></summary>

Меню позволяет поставить сбор на паузу, открыть сайт или настройки, перейти к расширению, данным и журналу, полностью выйти из Activity Tracker. Сайт запускается отдельно. Двойной щелчок открывает настройки уже работающего трекера.

Для запуска без установки распакуй `ActivityTracker-<версия>-windows-x64.zip` целиком и открой `ActivityTracker.exe`. Файлы runtime, `assets`, `chrome` и `node_modules` должны оставаться рядом. Сборка не подписана сертификатом издателя.

</details>

## Данные остаются локально

Установленное приложение хранит SQLite и ключи в **`%USERPROFILE%\.activity-tracker`**, отдельно от программы. Обновление или удаление программы не удаляет историю. API доступен только на `127.0.0.1:3536`; облака и удалённой передачи в этой версии нет.

<details>
<summary><strong>Какие данные используются и какие ключи нужны</strong></summary>

Сохраняются интервалы, названия окон/вкладок, домены и технические признаки источника. Текст переписки, содержимое документов, значения нажатых клавиш и аудиозаписи не собираются.

- **`read`** предназначен для сайта: чтение истории, правила и управление сбором.
- **`ingest`** предназначен для расширения: отправка наблюдений и ограниченные настройки сборщика.

Настройки трекера доступны без сайта на `http://127.0.0.1:3536/control/`; открывай их из трея. Не передавай ключи сторонним сайтам. Требования и границы API: [контракт v1](docs/api-v1.md).

</details>

<details>
<summary><strong>Разработка, сборка и интеграция</strong></summary>

Требуется Node.js 24.12+.

```sh
npm ci
npm run build
npm run desktop
```

`npm start` запускает API без трея. Из исходников данные по умолчанию находятся в `data/`. На других системах доступны API и приём событий Chrome; готовый установщик и нативные сборщики предназначены для Windows x64.

```sh
npm run verify
npm run prepare:installer
npm run package:windows
```

Проверяются строгие типы, границы модулей, линтер, сборка, интервалы, перезапуск и сохранение идентичности устройства. Функции ограничены 20 строками и когнитивной сложностью 20.

[Архитектура](docs/architecture.md) · [API v1](docs/api-v1.md) · [Полное руководство](docs/guide.md)

</details>
