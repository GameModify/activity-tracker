Activity Tracker теперь доступен как приложение Windows x64 с фиолетовым значком в трее.

- Пауза, переход в Time & Games, настройки подключения и выход из меню значка.
- Локальная страница управления с числом минут бездействия и копированием ключей для сайта и Chrome.
- Установщик для текущего пользователя и переносимый ZIP; Node.js включён в сборку.
- Отдельный архив браузерного расширения и контрольные суммы SHA-256.
- Сохранение правил, ключей и идентичности устройства после перезапуска. Чистое завершение закрывает интервалы на последнем подтверждённом событии.

Сайт запускается отдельно. Автозапуск трекера выключен по умолчанию. Сборка Windows не подписана сертификатом издателя; удаление программы сохраняет пользовательские данные.
