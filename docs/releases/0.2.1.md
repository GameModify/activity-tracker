Исправлена потеря подключения после повторного запуска трекера.

Windows могла перенаправлять AppData при запуске из пакетного приложения. Обычный запуск с рабочего стола открывал другой набор базы и ключей, из-за чего сайт и расширение получали HTTP 401.

- Общий каталог данных: `%USERPROFILE%\.activity-tracker`, одинаковый для разных запускающих приложений.
- Миграция использует физический каталог прежней базы и сохраняет проверенный снимок вместе с ключами в `legacy-backups`.
- Смена запускающего приложения не заменяет существующую общую базу или ключи.
- Добавлена проверка собранного EXE: два запуска с разными AppData сохраняют идентичность устройства и авторизацию.

Автозапуск остаётся необязательным, сайт запускается отдельно. Расширение 0.8.0 совместимо с этой версией.
